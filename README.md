# Uber Eats — Restaurant Landing Page

Responsive landing page for "Traktir Pushkin" restaurant, based on Uber Eats design.

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Mobile First approach
- Accessibility (a11y)
- Hover animations

## Live Demo
ue-restaurant-page.vercel.app

## Features
- Semantic HTML
- Responsive design for 3 breakpoints (320px, 768px, 992px)
- Optimized images (WebP)
- Clean, structured CSS
